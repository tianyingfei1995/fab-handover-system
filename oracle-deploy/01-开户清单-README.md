## 三、开户步骤（分步）

> 全程在浏览器操作，无需服务器。注册地址：**https://signup.cloud.oracle.com**

1. **进入注册页**：打开 `https://signup.cloud.oracle.com`，点击「Start for free」。
2. **填写账号信息**：国家/地区、姓名、邮箱、密码（需符合复杂度）。
3. **邮箱验证**：查收验证邮件，点击链接激活。
4. **填写手机号**：选择国家区号，输入手机号，接收短信验证码。
5. **添加支付方式**：输入信用卡/借记卡信息。这会进行一次 **1 美元以内的预授权验证（仅验证，不扣费）**，随后解冻。
6. **选择 Cloud Account 类型 & 数据中心**：选 **Always Free / 免费账户类型**；数据中心（Home Region）建议就近选 **首尔 / 东京 / 新加坡 / 孟买**（对国内访问延迟较低）。
7. **提交**：系统创建账户，可能进入"审核/就绪"状态，稍候即可登录控制台。

> 注意：注册时**务必不要**在控制台点击「Upgrade / 升级到付费(Pay-As-You-Go)」。Always Free 用户不开通 A1 实例时无需升级；若你想用满 4 OCPU 配额，部分账号需升级为免费但带 PAYG 卡验证，按 Oracle 最新政策执行即可。

## 四、免费资源配额速查（Always Free）

| 资源 | 免费额度 |
|------|---------|
| Compute (A1 ARM) | **4 OCPU + 24 GB RAM**（可按需拆分，如 1*4OCPU 或 2*2OCPU 等） |
| 块存储 Block Volume | **200 GB 总量**（免费） |
| 公网 IPv4 | 每月一定量免费（详情见控制台 Always Free 标签） |
| 出站带宽 | 每月一定量免费（超出才计费） |

> 项目预估用量：本系统（Node + SQLite 小规模）在 **1 OCPU + 6 GB** 配置下即可流畅运行，剩余配额还能再跑多台服务。

## 五、登录后创建虚拟机（Compute Instance）清单

登录 OCI 控制台后，创建第一台 VM：

| 项目 | 建议值 |
|------|--------|
| 映像（Image） | **Ubuntu 24.04 LTS**（或 22.04，本脚本按 Ubuntu 编写） |
| 架构（Shape） | **VM.Standard.A1.Flex（ARM）** |
| 配置 | OCPU 2 + 内存 12 GB（或 1+6，够用；配额内免费） |
| 引导卷大小 | 50 GB（配额内免费） |
| 网络 | 新建 VCN + 子网，勾选**分配公网 IP** |
| SSH 密钥 | **必须上传你的公钥**（见第六节），这是唯一登录方式 |
| 防火墙/入站规则 | 开放端口 **22**（SSH）、**80**（HTTP）、**443**（HTTPS），及本项目端口 **3000** |

## 六、准备 SSH 密钥

部署全程用 SSH 登录服务器，需要一对密钥：

- **Windows**（PowerShell/Git Bash）：`ssh-keygen -t ed25519 -f C:\Users\你的用户名\.ssh\fab_key` （一路回车）
- **macOS / Linux**：`ssh-keygen -t ed25519 -f ~/.ssh/fab_key`
- 生成后得到两份文件：`fab_key`（私钥，自己保存）、`fab_key.pub`（公钥，上传到 Oracle 控制台创建 VM 时的 "SSH keys" 栏）

本脚本假设你在 `/root/fab-handover-system` 目录部署（见部署脚本说明）。
