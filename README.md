# FAB 生产日常交接系统

一套面向半导体 FAB 产线的日常交接管理平台，覆盖机台交接、LOT 交接、交接签到、值班问题、其他交接与 AR 交接等场景，具备完整的角色权限与部门数据隔离。

## 功能模块

- **机台近期交接 / 机台长期交接**：机台运行状态、报警信息、责任人维护，支持批量状态更新
- **LOT 交接**：批次异常、跟进描述与图片附件
- **交接签到表**：班次、地点、主持人、到会人员
- **值班问题**：问题分类、处理过程、解决方案与责任人确认
- **其他交接 / AR 交接**：日常事项与到期跟进
- **仪表盘**：跨模块数据概览与图表统计
- **用户与权限**：用户管理、角色级 / 用户级权限配置、登录日志
- **部门管理**：部门维护

## 角色与权限

| 角色 | 能力 |
|------|------|
| 系统管理员 (admin) | 全部权限，可跨部门查看与操作，管理所有用户与角色权限 |
| 部门管理员 (dept_admin) | 本部门数据全权限，管理本部门用户，每部门仅一位 |
| 编辑者 (editor) | 本部门数据的查看 / 新增 / 编辑 |
| 查看者 (viewer) | 仅查看本部门数据 |

核心安全特性：

- 部门数据隔离：非管理员仅能访问本部门数据，服务端强制写入归属部门，禁止客户端篡改
- 登录防暴力破解：连续失败自动锁定
- 首次登录强制改密
- 会话 24 小时超时
- 图片上传魔数校验
- 富文本 XSS 过滤

## 技术栈

- 后端：Node.js + Express + better-sqlite3
- 认证：bcrypt + 令牌（不包含密码明文）
- 前端：原生 HTML / CSS / JavaScript（无构建步骤）
- 图表：Chart.js（本地化 vendor 文件）

## 快速开始

依赖：Node.js 18+

```bash
npm ci            # 安装依赖
npm start         # 启动，默认端口 3000
```

访问 `http://localhost:3000`。

### 默认账号

首次启动时系统自动创建默认系统管理员：

- 工号：`admin`
- 密码：`admin123`

> **安全提示：** 上线前请立即登录并修改默认管理员密码。

系统管理员可在「用户与权限」中创建部门管理员、编辑者、查看者账号。

## 环境变量

| 变量 | 说明 | 默认 |
|------|------|------|
| `PORT` | 服务端口 | `3000` |
| `ALLOWED_ORIGINS` | 允许跨域来源白名单（逗号分隔，留空默认仅同源） | 空 |
| `NODE_ENV` | 运行环境 | - |

## 目录结构

```
.
├── server.js              # 后端服务（路由、鉴权、业务逻辑）
├── public/
│   ├── index.html         # 前端页面
│   ├── css/style.css      # 样式
│   ├── js/app.js         # 前端逻辑
│   └── lib/               # 本地化的第三方库
├── data/                  # SQLite 数据库（运行时生成，勿提交）
├── oracle-deploy/         # Oracle Cloud 部署脚本
└── render.yaml            # Render 部署配置
```

## 部署

- 本仓库附带 `oracle-deploy/`（Oracle Cloud 免费层部署脚本）与 `render.yaml`（Render 平台配置），按需选择。
- 生产环境请务必：修改默认管理员密码、配置 `ALLOWED_ORIGINS`。

## 说明

- `data/` 目录（含 SQLite 数据库与上传图片）为运行时数据，已加入 `.gitignore`，不会提交到代码库。
- 首次启动会自动建表并创建默认管理员与默认部门。
